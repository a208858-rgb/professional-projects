# Project Overview

This folder contains the core implementation code for the project.

## Standards
- Write modular, readable, and documented code.
- Keep scripts reproducible and easy to run.
- Add clear comments where logic is non-trivial.

## Typical Files
- `scripts/` for automation or command-line tools
- `src/` for reusable source modules
- `main.py` or application entry points
- analysis scripts and pipeline files
