## Data and Responsible Use

- Do not commit private, sensitive, restricted, or identifiable data.
- Check the data provider's license and access terms before redistributing any dataset.
- Large raw and processed data folders are excluded by `.gitignore`; add documented download instructions or approved data access steps instead.
- Commit only results that are safe to share and useful for understanding or reproducing the project.
