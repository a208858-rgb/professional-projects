# Results Folder

This folder stores analysis outcomes, generated outputs, and reports.

## Suggested Structure
- `figures/`: charts, plots, images, dashboards
- `reports/`: summaries, markdown reports, PDF exports
- `tables/`: extracted tables or data snapshots

## Best Practices
- Save final outputs in a consistent format.
- Keep results traceable to the relevant code or dataset version.
- Add brief summaries alongside major deliverables.
